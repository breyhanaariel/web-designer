## What a recruiter can verify quickly

- Three clearly different commercial website categories: SaaS, ecommerce, and hospitality.
- Each project has a real public production deployment rather than only static screenshots.
- Each project has responsive layouts, multiple routes, interaction states, metadata, and a written case study.
- GitHub Actions verifies install, lint, TypeScript, and production builds.
- The work clearly identifies fictional concept content and avoids invented client metrics.
- The root portfolio links to related UI/UX and Front-End portfolios without duplicating their positioning.

## Accessibility & responsive review

Implemented and checked at code/live-route level:
- semantic page landmarks and heading structures
- real buttons for state-changing controls
- form labels on demo/booking flows
- ARIA state on tab/filter controls where used
- native keyboard focus retained
- reduced-motion CSS support
- narrow-screen responsive breakpoints
- no critical information dependent on hover alone
- concept forms clearly disclose that data is not submitted

The sites target WCAG 2.2-informed AA design. A formal third-party conformance certification is not claimed.

## Final recruiter assessment

The portfolio now presents a coherent Web Designer identity: expressive visual direction plus practical implementation. DaisyDesk proves structured SaaS/marketing work, Fawn & Finch proves commercial editorial/ecommerce thinking, and Moonpetal House proves immersive hospitality storytelling without sacrificing booking clarity.

The strongest portfolio behavior is the separation of disciplines: this repository focuses on brand-led commercial websites, while the linked UI/UX and Front-End repositories can carry deeper product-research and engineering proof.
