# 🎀 Portfolio Visual Asset Guide

The repository intentionally begins with coded visual systems and lightweight SVG brand assets so the sites remain functional before final photography/mockups are created.

## Cover Assets To Create
| Project | Cover direction | Recommended output |
|---|---|---|
| 🌼 DaisyDesk | Pastel SaaS browser mockup with dashboard/product cards | 1600×1000 PNG/WebP |
| 🦌 Fawn & Finch | Editorial fashion storefront with animal-inspired accessories | 1600×1000 PNG/WebP |
| 🌙 Moonpetal House | Dreamy boutique-retreat hero with editorial booking UI | 1600×1000 PNG/WebP |

## Per-Project Finished Visuals
Each project README contains a project-specific shot list. Keep mockups honest: use the actual coded interface and clearly mark speculative photography/brand assets as concept work.

## Image Standards
- Prefer WebP/AVIF for live-site photography.
- Keep decorative SVGs lightweight.
- Provide meaningful alt text for informative images and empty alt text for purely decorative imagery.
- Export mobile and desktop screenshots from the implemented site rather than recreating fake browser UI in static comps.
